# Caps Lock Göstergesi

Caps Lock, Num Lock ve Scroll Lock durumunu ekranda, sesle ve sesli okumayla bildiren, pil dostu Windows uygulaması.

**Microsoft Store:** https://apps.microsoft.com/detail/9N45SQH7MMCJ

- 9 konumlu, ayarlanabilir ekran bildirimi (süre, renk, boyut, saydamlık)
- Şifre alanında büyük harf uyarısı
- Yanlışlıkla Caps Lock basma koruması (basılı tut / çift bas)
- 6 ses paketi, kendi .wav dosyanız ve sesli okuma (Türkçe, English, Deutsch)
- Kısayol tuşu, sessiz saatler, istatistikler
- Açık / koyu tema, Windows 10 ve 11 (x64, ARM64, x86)
